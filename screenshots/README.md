# Screenshots

This folder is intentionally empty in the current commit.

Real Packet Tracer screenshots (topology view, `show` command output,
browser view of the college portal, ACL-blocked ping proof, etc.) can
only be captured honestly after the topology is actually built and
tested inside the Packet Tracer GUI — see [`../BUILD_GUIDE.md`](../BUILD_GUIDE.md)
step 7 for the exact list to capture.

No placeholder or fabricated images have been added here, consistent with
this project's approach of not representing anything as verified that
hasn't actually been run and observed.
